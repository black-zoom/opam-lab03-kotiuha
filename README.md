## Завдання 1. Обхід каталогів

Рекурсивно знайдено найбільший файл у каталозі `/home/user/Music/`.

- Ім'я: `FunRap Manhwa - Peak Martial Arts.mp3`

**Базовий випадок:** якщо каталог не містить підкаталогів, рекурсивні виклики не виконуються, а функція повертає найбільший знайдений файл або `null`.

## Завдання 2. Розбиття навпіл

Масив із 16 чисел, створений через `new Random(14)`:

```text
[-19, 17, 2, 2, 1, 12, -13, -1, 9, -3, 4, -4, -10, 10, 12, 11]
```

- Результат: `False`
- Максимальна глибина рекурсії: `4`
- log2(16) = 4

**Базовий випадок:** якщо `lo == hi`, діапазон містить один елемент, тому функція повертає `true`.

## Завдання 3. Перебір із поверненням

Знайдено всі способи розміняти 9 грн монетами номіналом 1, 2 і 5 грн.

| Монети 1 грн | Монети 2 грн | Монети 5 грн |

**Кількість способів: 8.**

**Базовий випадок:** коли всі номінали розглянуто, спосіб зараховується, якщо залишок суми дорівнює нулю.

## Завдання 4. Трасування

Масив: `[7, -2, 15, 4]`.

```text
enter Solve(0..3)
  enter Solve(0..1)
    enter Solve(0..0)
      -> true (один елемент)
    exit  Solve(0..0) -> true
    enter Solve(1..1)
      -> true (один елемент)
    exit  Solve(1..1) -> true
  exit  Solve(0..1) -> False
  enter Solve(2..3)
    enter Solve(2..2)
      -> true (один елемент)
    exit  Solve(2..2) -> true
    enter Solve(3..3)
      -> true (один елемент)
    exit  Solve(3..3) -> true
  exit  Solve(2..3) -> False
exit  Solve(0..3) -> False
```

Рядки `exit` з'являються у зворотному порядку до `enter`, оскільки вкладені виклики завершуються перед поверненням до попередніх. Це відповідає принципу LIFO: останній виклик завершується першим.

## Завдання 5. Ітеративна версія

- Рекурсивний результат: `False`
- Циклічний результат: `False`
- Результати збігаються: `True`

**Який запис зрозуміліший?**

Для перевірки однаковості елементів циклічний запис простіший, оскільки достатньо послідовно порівнювати кожен елемент із першим. Рекурсивний запис демонструє поділ навпіл, але створює додаткові виклики.

**Чому обхід каталогів складніше переписати циклом?**

Рекурсія автоматично зберігає в стеку викликів поточний каталог і місце повернення. Для ітеративного обходу потрібен власний стек каталогів, у якому зберігаються шляхи до ще не оброблених папок.

## Перевірка крайових випадків

| Вхід | Завдання | Очікувано | Отримано |
|---|---|---|---|
| Порожня папка `/tmp/lab03-empty` | 1 | Файл не знайдено | Файлів не знайдено або немає доступу |
| Папка `/tmp/lab03-denied` без доступу | 1 | Програма не падає | Файлів не знайдено або немає доступу |
| Масив `{5}` | 2 | `true` | `True` |
| Масив `{4, 4, 4, 4}` | 2 | `true` | `True` |
| Масив `{4, 4, 5, 4}` | 2 | `false` | `False` |
| Сума `-1` | 3 | `0` способів | `0` |

Додатково перевірено вкладені каталоги: найбільший файл `c.txt` має розмір 20 байт. Рекурсивна й ітеративна версії завдання 2 повертають однаковий результат `False`.
